# Historical inert settings

> This page belongs to the archived Windows implementation. It is retained so old release notes keep
> their links; it is not a current settings contract.

Older Windows builds removed or disabled settings whose data sources were unavailable, including smart
beat models, custom uploads and unsupported subtitle modes. The current Linux settings page omits
platform features that cannot work in the Qt/Wayland host.

See [`../protocol.md`](../protocol.md) and [`../linux-runtime.md`](../linux-runtime.md) for the current
contract.
