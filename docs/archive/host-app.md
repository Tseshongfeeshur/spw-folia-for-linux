# Historical Windows host summary

> This page describes the former Windows/WebView2 helper. It is retained only to keep archive references
> readable.

The old host owned a Windows window, WebView2, WASAPI capture and transparent input path. The current
host is a Qt6 Linux process using QtWebEngine, Wayland, Plasma tray APIs and PipeWire.

See [`../architecture.md`](../architecture.md), [`../linux-runtime.md`](../linux-runtime.md) and
[`../protocol.md`](../protocol.md).
