# Research notes

The notes under this directory are historical research for the former Windows implementation. They
may mention WebView2, WASAPI, OBS, Windows paths and private Salt Player classes because those were the
assumptions being investigated at the time.

They are not current runtime documentation. For the Linux implementation, use [`../docs/`](../docs/),
especially [`linux-runtime.md`](../docs/linux-runtime.md), [`architecture.md`](../docs/architecture.md)
and [`protocol.md`](../docs/protocol.md).
