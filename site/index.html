01 — 真身

你看到的是真正的 Folia

插件不重画 Folia 的动画。Linux 包内的 web bundle 由 QtWebEngine 加载， Qt 宿主负责窗口、托盘、协议桥和音频分析，页面仍由 Folia 渲染器绘制。

逐字发光

每个字都有自己的入场时序与辉光，跟着逐字时间轴亮起来，而不是整行淡入。

封面取色

从专辑封面提取主色调，歌词配色随之变化；换一首歌，就是换一片天色。

同步到播放器

播放、暂停、切歌和定位通过公开 Workshop API 同步，不依赖播放器私有类或反射控制。

03 — 各走各的通道

让高频数据留在宿主里

Kotlin 插件只同步播放所需的低频状态。PipeWire 采样、FFT、频谱压缩和五频段计算都在 Qt 宿主完成， 音频帧直接注入页面，避免把高频数据绕回 JVM。

04 — Linux 边界

系统依赖写在明面上

这是 Linux-only 版本。窗口使用 Qt 的 Wayland 平台插件，托盘使用 Plasma StatusNotifier， 音频使用 PipeWire sink monitor；Qt、QtWebEngine、Wayland、Plasma 和 PipeWire 由系统提供。

  • 目标环境：Linux x86_64 + Wayland + KDE Plasma
  • 不提供 X11 回退，也不打包 Qt 或 PipeWire
  • 不支持透明窗口、鼠标穿透、Windows/WebView2、WASAPI 和队列控制
  • 入口包括配置页按钮、公开快捷键、Plasma 托盘；SPW 1.19.3 “更多”菜单使用公开 HookRegistrar

05 — 一样的手感

沿用 Folia设置体系

播放页右下角沿用 Folia 原版侧边面板动画；控制页保持清爽，只保留歌曲信息、歌词样式、背景类型和颜色主题。面板内的设置按钮直接打开 Folia 原版歌词样式调参弹窗。设置树由插件持久化，页面和播放窗口使用同一份配置。

  • 14 种样式、纹理分辨率、镜头和文字动势调节
  • 页面预览与播放状态、歌词、封面和真实时钟同步
  • 不可用的 Windows 专属设置不会出现在 Linux 页面

06 — 开始使用

四步，装进播放器

当前版本面向 Salt Player 1.19.3 的 Linux x86_64 Wayland + KDE Plasma 环境。

  1. 1

    安装系统依赖

    准备 Qt 6 Widgets、QtWebEngine、PipeWire libpipewire-0.3、KDE Frameworks 6 KStatusNotifierItem、Wayland 和 Plasma 托盘支持。

  2. 2

    导入 Linux 插件包

    从 GitHub Releases 下载 Linux x86_64 的 .spmod，在 Salt Player 的创意工坊中导入。

  3. 3

    启用公开权限

    按 Salt Player 提示授予 library-read、key-bindings 和 class-transform。后者只用于公开 Workshop HookRegistrar 菜单入口。

  4. 4

    从配置、菜单或托盘打开

    插件配置页提供“打开 / 显示 Folia”按钮；SPW 1.19.3 的“更多”菜单、公开快捷键（默认 Ctrl+Alt+F）和 Plasma 托盘也都可打开。

运行时提醒

插件包不携带桌面运行时

Qt、QtWebEngine、Wayland、KDE Plasma 和 PipeWire 必须由 Linux 系统安装。宿主首次启动后会常驻托盘，禁用或卸载插件时退出。
